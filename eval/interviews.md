# Developer interviews

Ask five developers. Ask the three questions. Write the answers below. Then record each interview with `eval/record.mjs --interview` (see `eval/README.md`).

| # | Who (name, team) | 1. How many PRs wait for testing now? | 2. When did a preview bug last reach production? | 3. Would a paused broken session help? Why? | Notes |

| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| 4 |  |  |  |  |  |
| 5 |  |  |  |  |  |

Rules:

1. Ask the questions in this order.
2. Write the answer in the words of the developer. Do not change the answer.
3. If the developer does not know, write "does not know".
